# NoiseScope 模型假设

本文档只整理项目书第 4–8 节已给出的假设与边界，不引入新模型、
新参数或新结论。数值门禁见项目书第 13–14 节与
`HOW_TO_REPRODUCE.md`。

## 1. 状态与守恒

- 唯一状态变量为 B 的分子数 `j`，`0 ≤ j ≤ jMax`。
- 二聚模型 `2A ⇌ B`：总单位 `N = A + 2B`，故 `A = N − 2B`，
  `jMax = floor(N/2)`。默认 N=20 时 jMax=10。
- 线性模型：`A = N − B`，`jMax = N`。默认对照 N=20 时 jMax=20。
- 状态只在相邻整数间跳变：正向 `j → j+1`，反向 `j → j−1`；
  边界处对应速率为 0 时正确吸收，不产生越界状态。

## 2. 速率与单位

- 正向速率：二聚 `λ(j) = kf · A(A−1) / 2`，其中 `A = N − 2j`；
  线性 `λ(j) = kf · A`，其中 `A = N − j`。
- 反向速率：`μ(j) = kb · j`，两种模型相同。
- 时间单位为秒，速率单位为 1/秒，漂移单位为分子数/秒，
  方差修正（driftCorrection）单位也是分子数/秒，
  与 meanGap（分子数）不可混淆。
- 二聚组合数 `A(A−1)/2` 不可漏掉 1/2，也不可用 `A²` 代替；
  这是方差修正的来源，也是最常见的实现错误。

## 3. SSA 与随机流

- 采用直接法（Gillespie direct method）：每步先按总速率
  `a0 = λ + μ` 抽等待时间 `τ = −ln(uWaiting) / a0`，
  再按 `uChoice · a0` 与 λ 的比较决定正向或反向。
- 随机数发生器为 xorshift32，种子派生按项目书 §5.2：
  轨迹种子由主种子、轨迹索引与组别盐混合得到，
  同一环境内重复运行得到相同轨迹、审计事件与初始抽样。
- 初始状态由初始 PMF 抽样得到（uInitial），不是由均值反推；
  终止候选（HORIZON）是未发生的候选，不是已发生事件。
- 事件恰在视界 T 时执行更新，最后观测取新值；
  候选事件在 T 之后时不执行，最后观测取旧值。
- 限制：N ≤ 40，观测点 101 个，每组轨迹数 64–4096。
  全量事件不堆积内存：聚合只保留 counts、均值、方差与
  preview（每组最多 32 条轨迹的 101 点采样）。

## 4. CME 概率基准

- 有限状态生成矩阵 Q 由上述速率构成，行和为 0；
  概率演化用 uniformization 求解，ν 为 uniformization 速率，
  要求 ν ≤ 40，否则拒绝而非静默近似。
- 数值预算：单步误差 ≤ 1e-14，累计尾界 ≤ 1e-12，
  质量亏缺绝对值 ≤ 1e-10，最小概率 ≥ −1e-14；
  超预算时抛出 `NumericConvergenceError`，不返回静默通过的结果。
- 零速率时 ν=0，分布保持初始状态；这不是数值失败。

## 5. 均值闭合与三种差异

- 闭合是近似：它只跟踪均值，用闭合漂移代替真实漂移，
  因此与 CME 均值之间存在 meanGap。
- exactDrift 是在 CME 当前分布下算出的真实平均漂移；
  closureDriftAtExactMean 是在 CME 当前均值处算出的闭合漂移；
  driftCorrection = exactDrift − closureDriftAtExactMean。
- 二聚的 driftCorrection 等于 `kf · Var(A) / 2`（在分布层面）；
  线性模型的 driftCorrection 恒为 0。
- samplingError = SSA 经验均值 − CME 均值，是抽样误差，
  不是模型误差，也不是 meanGap 或 driftCorrection。

## 6. 统计诊断与不声称事项

- CDF/DKW 参考带仅用于 CDF：DKW 半宽
  `ε = sqrt(ln(2/0.05) / (2M))`，点态 95% 带，裁到 [0,1]。
  它不是全部时间的同时置信带，不是 PMF 每根柱子的误差棒，
  不验证 PRNG 的真正独立性。
- G07 固定种子门禁（CDF 距离 ≤ 0.06）是保守的统计回归检查，
  不是每条随机轨迹的精确等式，也不替代解析、单步和守恒测试。
- 本程序不模拟空间位置、碰撞过程、扩散或真实化学动力学；
  “合成有限反应模型，无空间碰撞模拟”这一说明应始终可见。
- 不声称：跨平台性能相同、Windows 实跑已验证（见 README）、
  浏览器堆峰值已硬断言（T014 未断言，见任务记录）。
